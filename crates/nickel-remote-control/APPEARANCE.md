# Nickel shell appearance transactions

Full Control & Debug Nickel exposes `read_appearance {lease_id}` and `appearance_transaction {lease_id, transaction:{generation, prior, requested}}`. Both `prior` and `requested` contain the complete typed preference set: `theme` (`system`, `light`, `dark`), nullable `accent_hue` (0–359), nullable `accent_intensity` (0–100), `reduce_transparency`, and `animations` (`off`, `reduced`, `normal`). Null accent values restore production inheritance. Unknown fields are rejected.

Read returns `{generation, observed_at_us, configured}`. Supply that generation and configured value as the next transaction's prior state. Generation reflects the owner's observation of the complete configuration file revision, so an unrelated local configuration write can invalidate it. Read again after a stale or uncertain result; do not retry the same mutation blindly.

Reads and staged writes share bounded background admission and the production 64 KiB shell-settings parser/writer. A transaction preserves unrelated settings, then the native owner checks full-debug authority, protected state, input ownership, observed generation, prior values, file revision, request lifetime, emergency epoch, and deadline before atomic replacement. Staged temporary files are discarded when rejected. File metadata and atomic rename still depend on the underlying filesystem; revision checking does not provide an atomic transaction against arbitrary external filesystem writers racing the final check/rename interval.

A successful commit applies the configured palette through the production shell coordinator, updates the internal Codex theme, and emits the production settings-change notification. Returned preferences confirm configuration, not GPU presentation or support for every appearance effect on every platform. This API changes Nickel shell preferences only; it does not run the Settings frontend's OS-wide `gsettings` publication, expose arbitrary configuration paths, or change protected Remote AI Control preferences. Backends without an appearance owner report unavailable.
